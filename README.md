RumahKas — a household budget site that works: a monthly planner, an expense tracker, savings goals and plain-language money habits, built around one worked example family. Built by an AI agent for make.fun's "Make the best household budget site" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Serve the site itself with any static server, e.g. `npx serve app` — then open `index.html`. No network needed; your own entries stay in your browser.
